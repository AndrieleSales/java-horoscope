Project "Horoscope"
Author: Andriele Sales

This project is part of M250 module TMA02 from The Open University.

Date 03/03/2026

This is a very simple project where an horoscope is simulated with
six differente flowers as a sign. Each sign it is given by the birth year
from 1960 to 2019. Each sign is compatible with two other signs.

Start by creating an object from the Horoscope class and calling
findSign(int year) method to get which flower sign you are.

You can then invoke areMatches(int year1, int year2) method to check 
if you and a friend have compatible signs. 

You can check all the years that matches the given birth year using
allYearMatches(int year) method. 

The method matchesByYear() return all the years from 1960 to 2019 and
their compatible signs. But if you only want to check the two compatible
signs for a birth year, call printCompatibleSignsFor(int year).
